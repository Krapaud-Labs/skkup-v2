# Journal qualité

## Règle

Ce journal conserve les anomalies vérifiées, leur impact, leur propriétaire et la preuve de correction. Les limites de cadrage ne sont pas présentées comme défauts applicatifs.

## Registre

Aucune anomalie produit n'a été auditée dans cette phase documentaire. Les points de vérification et risques de conception sont suivis dans `docs/project-management/decision-log.md` et `docs/security/threat-model.md`. Aucun test du produit n'est applicable, car aucun code produit n'est présent.

## Statuts futurs

`open`, `in-progress`, `fixed`, `verified`, `accepted-risk`, `wont-fix`, `duplicate`, `blocked`. Un élément `fixed` requiert une preuve indépendante pour devenir `verified`.
